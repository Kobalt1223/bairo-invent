Import format & quick instructions

This prototype accepts UTF-8 CSV (comma or semicolon separated), or a JSON backup exported here. Excel: use Save as → CSV UTF-8. Actual Barsy column mapping will be added once a sample export is available. XLSX files are not supported in this prototype.

CSV template header (category is optional; inferred from product name or set to Other):

name,category,location,quantity,unit,minimum,target

Example:

Campari,Other,Stockroom,2,bottles,3,12

Use consistent units and a decimal point. Stock quantities, units, minimums, targets, and locations in the starter file are illustrative. Replace them with your own values before operational use. Quantities must be non-negative and targets must be at least the minimum. PDF: tap Print / Save PDF and choose the device’s PDF option, if available. Stock exports and reports always include the full snapshot, regardless of filters.

Prototype only · Starter quantities and thresholds are examples · Figures are recorded stock, not a physical count · No live synchronization
